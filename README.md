# QA Automation with Playwright

Learner-facing site for the TypeScript + Playwright QA curriculum, built with Docusaurus.

## Local preview

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run serve
```

Pushing to `master` deploys to GitHub Pages via `.github/workflows/deploy.yml`. In the GitHub repo, set **Settings → Pages → Source** to **GitHub Actions**.
