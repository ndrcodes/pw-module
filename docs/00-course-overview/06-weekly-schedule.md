## Planned shape

The course runs **32 weeks × 2 sessions × ~90 minutes = 64 sessions**, allocated as follows:

| Weeks | Content | Sessions |
|---|---|---|
| 1-2 | Part I — Software Testing Fundamentals (Ch 1.1-1.4) | 4 |
| 3-9 | Part II — Programming Fundamentals (Ch 2.1-2.13, arrays split across two sessions) | 14 |
| 10 | Project 1 review + Project 2 build lab | 2 |
| 11 | Part III — Automation Fundamentals (Ch 3.1-3.2) | 2 |
| 12-15 | Part IV — API Testing and Automation (Ch 4.1-4.8) | 8 |
| 16 | Project 3 build lab + review | 2 |
| 17-19 | Part V — Web Automation (Ch 5.1-5.5, synchronization gets two sessions) | 6 |
| 20-24 | Part VI — Framework Engineering (Ch 6.1-6.9) + Project 4 kickoff | 10 |
| 25 | Project 4 build lab + review | 2 |
| 26-27 | Part VII — CI/CD (Ch 7.1-7.3) + pipeline lab | 4 |
| 28-29 | Part VIII — Professional Engineering (Ch 8.1-8.3) + capstone kickoff | 4 |
| 30-32 | Capstone build labs, flake clinic, demos and architecture defense | 6 |

Each week's entry will specify: week number, Session 1 topic, Session 2 topic, learning objectives, in-class activities, homework, coding assignment, quiz/assessment, and estimated difficulty (🟢/🟡/🔴).

Until this document is written, use the [Recommended Learning Progression](03-learning-progression.md#7-recommended-learning-progression-learner-facing) for sequencing and each Part's `00-module-overview.md` for pacing guidance.
